## Grants (one-time, to the workshop group — not per attendee)
Grant once to the group that contains all attendees (e.g. `analyst101_attendees`). Because each
attendee **creates their own** ETL schema, they automatically own it and get full control on it —
no per-schema grants to hand out.
```sql
-- shared dataset: read-only for everyone
GRANT USE CATALOG ON CATALOG {{CATALOG}} TO `analyst101_attendees`;
GRANT USE SCHEMA, SELECT ON SCHEMA {{CATALOG}}.{{SCHEMA}} TO `analyst101_attendees`;

-- let each attendee create + own their own ETL schema (they get ALL PRIVILEGES on what they create)
GRANT CREATE SCHEMA ON CATALOG {{CATALOG}} TO `analyst101_attendees`;
```
> In the ETL lab, each attendee runs `CREATE SCHEMA {{CATALOG}}.analyst101_<their-name>` themselves.
